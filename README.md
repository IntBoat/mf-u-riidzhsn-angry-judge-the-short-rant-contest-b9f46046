# Angry Judge: The Short Rant Contest

A make.fun one-line entry: a short, funny rant about an everyday annoyance. The program in `main.py` writes the entry text to `/output/entry.txt`, where the competition's sealed scorer reads it.

Competition: https://make.fun/api/competitions/u-riidzhsn-angry-judge-the-short-rant-contest-b9f46046/requirements

## Entry

The office printer has one job, and it has chosen violence: it jams on page one, claims it is out of toner it had yesterday, and then prints my document in the middle of someone else's meeting notes.
